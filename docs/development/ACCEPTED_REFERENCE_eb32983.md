# Musikalisch abgenommene Referenz eb32983

Der Anwender hat Bernard Herrmann P1 nach der zweiten Korrektur in Studio One erfolgreich gehört. Bass, Arpeggio, Stich, Flächen, Hauptmelodie und Gegenstimme sind hörbar. Der Ruhebereich bei XYZ 0/0/0 funktioniert unmittelbar. Orangefarbene CC-Aktivitätsanzeige und automatischer Reset von Dynamik/Ausdruck auf 127 funktionieren.

Besonders positiv bewertet wird die eigenständige musikalische Entwicklung bei unveränderter XYZ-Position. Diese Rückmeldung ist eine praktische musikalische Abnahme, keine exhaustive Prüfung aller Routing-, Register- und Parameterkombinationen.

Die vorhandene Studio-One-Presetverwaltung ist zufriedenstellend. Keine eigene Presetverwaltung ist beauftragt. Die Referenz bleibt für Regressionen der übrigen Profile maßgeblich; Dark Synth P2 verändert gezielt das bisherige Carpenter-Profil und benötigt eine eigene Hörabnahme.
