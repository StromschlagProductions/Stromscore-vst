# Stromscore 0.9

- Die Beschreibung im Kasten der Gegenstimme ist gekürzt und passt jetzt auch unter Windows vollständig hinein.
- Sonst wie 0.8: Genre-Schalter Score / 80er Pop-Rock, Dynamik per CC, Legato der Gegenstimme, MIDI zum Herausziehen, nächster Akkord, Feld-Karte.

Installation: ZIP entpacken, DAW schließen und den vollständigen Ordner `Stromscore.vst3` nach `C:\Program Files\Common Files\VST3` kopieren.
