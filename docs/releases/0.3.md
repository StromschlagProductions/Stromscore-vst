# Stromscore 0.3 – Ebenen schalten, Akkorden folgen oder bleiben

- **Jede Ebene einzeln schaltbar:** Aus, Auto (setzt bei ihrer VERLAUF-Stufe ein) oder An (spielt immer). So lässt sich zum Beispiel nur mit dem Bass oder nur mit einer Fläche beginnen.
- **Folgt den Akkorden oder bleibt:** Bei Fläche, Bass und Arp lässt sich einstellen, ob die Ebene den Akkordwechseln folgt oder auf dem Grundakkord bleibt, etwa ein durchlaufender Arpeggio-Ostinato über wechselnden Flächen.
- **Hängende Töne nach Stopp behoben:** Alle klingenden Noten werden bei Stopp, Sprung, Reset und Bypass sicher beendet, zusätzlich geht auf jedem Kanal ein „Alle Noten aus“ hinaus.
- **Untertitel:** „Audio Drama Underscore Inspirator“. Die Noten sind als Ausgangspunkt zum Weiterbearbeiten gedacht.
- Bestehende Projekte laden wie bisher (alle Ebenen auf Auto, alle drei auf „folgt den Akkorden“).

Installation: ZIP entpacken, DAW schließen und den vollständigen Ordner `Stromscore.vst3` nach `C:\Program Files\Common Files\VST3` kopieren.
